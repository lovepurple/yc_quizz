查看填写规范
  • Word：保留题型标题；每题用“1.”等题号开头；选项和“答案：”各占一段；分值写成“（2分）”。

  • 答案：单选填 A；多选填 AC；判断填“正确”或“错误”；填空题每题一个空，同义答案用 | 分隔。
  • 每题分值填写 0.01～100 的数字，最多两位小数；单次最多发布 50 题，上传后先核对再发布。
